# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## Categorías estándar que usa este equipo:
- `Added` para nuevas características o pantallas.
- `Changed` para cambios en funcionalidades o estilos existentes.
- `Deprecated` para características que se eliminarán pronto.
- `Removed` para características eliminadas.
- `Fixed` para solución de errores (bugs).
- `Security` para parches de seguridad.
